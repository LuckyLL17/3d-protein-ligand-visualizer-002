# 3D 蛋白质结构与配体结合可视化平台

React + Vite + TypeScript + React Three Fiber 的结构生物学可视化基础项目，用于展示蛋白质骨架、关键残基、配体原子和结合口袋关系。

## 当前能力

- 卡通带状、表面模型、原子视图切换
- 关键残基选择与空间定位
- 配体原子点击选择
- 配体旋转
- 关键残基、配体原子和相互作用图例
- 结合口袋指标卡片
- 残基角色、空间坐标、距离和作用类型展示
- 相互作用分析侧栏：基于残基/配体实际世界坐标计算近距离接触，按氢键、极性、疏水、范德华分类；距离阈值与类别筛选联动 3D 连线、残基列表标记和选中详情；支持从分析结果定位残基与配体原子；含计算中、无接触、坐标缺失三态

## 启动

```bash
npm install
npm run dev
```

当前使用内置示例结构数据，后续可接入 PDB/mmCIF 文件解析、真实原子键推断、分子对接结果、氢键几何筛选和结构比对。
